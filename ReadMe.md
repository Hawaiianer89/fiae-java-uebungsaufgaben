# FIAE – Java-Übungsaufgaben

Dieses Repository enthält eine Auswahl praktischer Java-Übungsaufgaben aus meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung.

Die Aufgaben behandeln grundlegende Programmierkonzepte und dienen dazu, die erlernten Kenntnisse praktisch anzuwenden und zu vertiefen.

## Aufgabenübersicht

| Aufgabe | Schwerpunkte |
|---|---|
| [Rückgeldautomat](01-rueckgeld-getraenkeautomat-while/aufgabe_rueckgeld.md) | While-Schleife |
| [Fahrkartenautomat](02-fahrkartenautomat-do-while/aufgabe_fahrkartenautomat.md) | Do-While-Schleife |
| [Schrittzähler](03-schrittzaehler-methoden/aufgabe_schrittzaehler.md) | Methoden, Eingabevalidierung |

## Aufbau

Jede Aufgabe enthält:
- Eine Beschreibung der Aufgabenstellung
- Meine kommentierte Java-Lösung

## Ziel

Die Sammlung dokumentiert meine praktische Auseinandersetzung mit Java und zeigt ausgewählte Lösungsansätze aus meiner laufenden Umschulung.
